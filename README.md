# 🤖 Enterprise AI Data Analyst

A privacy-first, full-stack SaaS application that analyzes CSV data using natural language queries powered by a **local LLM** (Ollama). Built with .NET 8 Clean Architecture and React.

## ✨ Features

- 🧠 **Natural Language to SQL** — Ask questions in plain Italian/English, get real SQL queries
- 🔒 **Privacy-First** — 100% local AI (Ollama + TinyLlama), zero data leaves your machine
- 📊 **Smart Visualizations** — Auto-generated Bar, Line, and Pie charts via Recharts
- 📥 **CSV Export** — Download query results with one click
- 📜 **Query History** — Sidebar tracks your last 10 queries
- 🛡️ **SQL Injection Protection** — Only SELECT queries allowed, regex sanitization
- ⚡ **Fast Response** — TinyLlama model optimized for sub-5s queries
- 🎨 **Modern Dark UI** — Tailwind CSS with responsive design
